# Snowflake DLA

A small Python program that generates **6-fold symmetric pseudo-snowflakes** from random walks. It's inspired by diffusion-limited aggregation (DLA): particles take stochastic, branching paths outward from a central seed, and the resulting branch is copied around the centre using the symmetry operations of a snowflake.

> This is a visual toy, not a physical model. It has no temperature, humidity or ice-crystal chemistry, and the particles don't stick to a growing cluster as in true DLA. The aim is to show how a simple stochastic process, plus symmetry, produces intricate, fractal-like patterns.

## How it works

Real snowflakes have 6-fold symmetry because water molecules form a hexagonal lattice when they freeze. Their symmetries form the dihedral group **D6** (rotations by multiples of 60° plus reflections). A plain random walk has no such symmetry, so the program grows **one** branch and then applies the symmetry itself:

1. Start a particle at the centre of the grid, moving straight up.
2. Step the particle forward. At every step there is a small chance it changes direction. The turn is shallow and the speed is kept roughly constant, so you get branching rather than random wandering.
3. Record the points the particle passes through, drawing slightly thickened lines so the pattern isn't wispy.
4. Repeat for several particles from the same centre, merging all their paths into one template branch.
5. Rotate the template in 60° steps around the centre and mirror it about the vertical axis to build the full snowflake.
6. Plot the grid with Matplotlib.

Each run is random, so every snowflake is different.

## Parameters

Set at the top of `main.py`:

| Parameter | Default | Effect |
|---|---|---|
| `branch_probability` | `0.005` | Chance per step that a particle changes direction. Higher values give more branching |
| `complexity` | `0.02` | Controls the number of particles: `int(complexity × size_coeff)`, so 4 by default. More particles make a denser pattern |
| `size_coeff` | `200` | Sets the grid size (`max_speed × size_coeff` cells square) and how many steps each particle takes, so it sets the snowflake's size |
| `max_speed` | `3` | Particle speed in grid cells per step |

## Example pictures

The `Example Pictures/` folder contains snowflakes generated by the model while varying the parameters. In the file names, the first digit is the branching level (`0`–`3`, increasing) and the second digit is the particle-count level (`1`–`5`, increasing). `01.png` is the sparsest and `35.png` the densest.

## Installation and usage

```bash
git clone https://github.com/n03-sc08/snowflake_dla.git
cd snowflake_dla
pip install numpy matplotlib
python main.py
```

A Matplotlib window opens with the snowflake. Use its save button to export an image, or edit the parameters above and run again.
